In this lesson, you will transfer files between your Windows computer and DelftBlue using the `scp` command.

## Learning objectives

By the end of this lesson, you will be able to:

- identify the local and remote parts of an `scp` command;
- upload a file from Windows to DelftBlue;
- upload a folder to DelftBlue;
- download a file from DelftBlue;
- download a folder from DelftBlue.

## Before you begin

You need:

- DelftBlue access;
- Terminal, PowerShell, or Command Prompt;
